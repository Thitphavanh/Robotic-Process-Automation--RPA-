## 🔧 Technical Implementation

### Smart Features

#### 1. Dynamic Stock Discovery (Gemini AI)
- ใช้ Gemini AI Agent ค้นหาหุ้น Top 10 แบบอัตโนมัติ
- อัพเดทรายการหุ้นตามความนิยมและ market cap
- ไม่ต้อง hardcode symbol list

#### 2. Multi-Currency Support
- **THB (฿)**: Lazada, Shopee, Thai Gold
- **USD ($)**: Amazon, Alibaba, Crypto, Gold Spot
- **CNY (¥)**: Taobao, Tmall, Pinduoduo, 1688
- **EUR (€)**: Europe Stocks

#### 3. Intelligent Price Extraction
```python
# Removes currency symbols
price_text.replace('฿', '').replace('$', '').replace('¥', '')

# Handles commas
price_text.replace(',', '')

# Extracts from ranges
"$10-$20" → 10.00  # Takes minimum price
```

#### 4. Language-Specific Headers
```python
# Thai sites
headers = {'Accept-Language': 'th-TH,th;q=0.9'}

# Chinese sites
headers = {'Accept-Language': 'zh-CN,zh;q=0.9'}

# English sites
headers = {'Accept-Language': 'en-US,en;q=0.9'}
```

#### 5. Error Handling & Resilience
- Individual platform failures don't affect others
- Graceful degradation for unavailable sources
- Timeout protection (10-15 seconds per request)
- SSL verification disabled for problematic sites

#### 6. Data Enrichment
- Platform prefix in titles: `[Lazada Flash Sale] Product Name`
- Source attribution: `[Yahoo Finance] Market News`
- Automatic URL normalization
- Timestamp tracking

## 📊 Data Structure

### Database Model (NewsArticle)
```python
{
    'title': str,           # Product/Article title with platform prefix
    'content': str,         # Full description
    'url': str,             # Direct link
    'price': Decimal,       # Price (15 digits, 2 decimals)
    'change': Decimal,      # Price change (for stocks/crypto/gold)
    'change_percent': Decimal,  # % change
    'image_url': str,       # Product/Article image
    'category': str,        # e_commerce, stock_thai, crypto, etc.
    'published_at': datetime,
    'scraped_at': datetime,
    'source': ForeignKey(NewsSource)
}
```

## ⚠️ Important Notes

### Legal & Ethical Considerations
1. **Respect robots.txt**: Check each site's robots.txt
2. **Rate Limiting**: Add delays between requests
3. **Terms of Service**: Comply with each platform's ToS
4. **Official APIs**: Prefer official APIs when available:
   - Lazada Open Platform (open.lazada.com)
   - Shopee Open Platform (open.shopee.com)
   - Amazon Product Advertising API
   - CoinGecko API (already used)

### Technical Limitations
1. **Dynamic Content**: Many e-commerce sites use JavaScript
   - Current: HTML parsing with BeautifulSoup
   - Upgrade: Consider Selenium/Playwright for JS rendering

2. **Anti-Bot Protection**:
   - Chinese platforms (Taobao, Tmall, Pinduoduo) have strict protection
   - Amazon has sophisticated anti-scraping
   - Solution: Use proxies, rotate user agents, add delays

3. **Selector Volatility**:
   - E-commerce sites frequently update their HTML
   - Stock news sites may change layouts
   - Maintenance: Regular selector verification required

### Performance
- **Sequential Scraping**: ~2-5 minutes for all categories
- **Parallel Option**: Use ThreadPoolExecutor for faster scraping
- **Network Dependent**: Speed varies based on network latency

## 🆘 Troubleshooting

### No Data from E-Commerce
1. Check if site is accessible
2. Verify CSS selectors (use browser DevTools)
3. Test with different user agents
4. Check for CAPTCHA or anti-bot measures

### Price Extraction Fails
1. Inspect HTML structure manually
2. Update price extraction regex
3. Handle multiple currency formats
4. Test with sample HTML

### Slow Scraping
1. Reduce timeout values
2. Limit concurrent requests
3. Use connection pooling
4. Consider async scraping
